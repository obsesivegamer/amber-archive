Amber is a time capsule for web pages. It takes a snapshot of a webpage that will still be here even if the original page disappears. It saves a text copy and a graphical copy of the page for better accuracy, and gives you a short, reliable link to an unalterable record — including pages from modern JavaScript sites.

Useful when a page might change soon: a price list, a job offer, a real-estate listing, a blog post. Saved pages have no active elements and no scripts, so they cannot pop up or run malware.
